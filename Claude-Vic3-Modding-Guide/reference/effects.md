copy-paste slips; known ones are listed in chapter 15 of the guide.

## random_list
- **Scopes:** none

```
Selects one effect from a weighted random list and executes it.
random_list = {
  10 = {
	trigger = { enable / disable this effect }
	modifier = {
		if = {
			limit = { is_foo }
			add = 10
		}
		# Note: can have multiple conditions in the same `modifier` block to
		# have different scenarios affect the chances differently
		if = {
			limit = { is_bar }
			add = 20
		}
	}
	# Warning: do _not_ add multilpe `modifier` blocks, since only the last one
	# is taken into consideration. Instead, use multiple `if` conditions inside
	# only one `modifier` block (one for each effect, that is)
	<effect_1>
  }
  30 = {
	# trigger is optional, leaving it out means this effect is enabled
	# modifier is also optional, it means that the base weight (30) is final
	# Note: totally fine to have a `modifier` block here. It's important to only
	# have one `modifier` block per effect, not one in total.
	<effect_2>
  }
}
The effects are weighted by their relative weights (10 and 30 in the example).
E.g. in this example the first effect has a base 25% chance of being picked,
while the second effect has a 75% base chance. The chance is given by the
formula `Wn / Wt` where `Wn` is the weight of a specific event while `Wt` is the
sum of all the weights. So the chances in the example are, respectively,
10 / 40 (25%) and 30 / 40 (75%).
The weight of an effect can be modified by a `modifier` block. In the example,
if the scoped object satisfies the `is_foo` trigger, its relative weight
increases by 10. So in that situation, the relative weights would be 20 and 30
rather than 10 and 30, meaning the chances would be 40% and 60% rather than
25% and 75%.
```
