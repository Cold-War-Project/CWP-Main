### 11. Dominion pacts
Log: dominion GBR->{CYP,HND,IRQ,NZL,SAF} cannot be maintained. CAN/AST (country_type colonial) produced no warning; the five failing countries are `recognized`. Vanilla subject_type_dominion only allows `valid_subject_country_types = { colonial }`, minor-or-lower ranks and a higher-ranked overlord. Patch: add recognized/unrecognized, add great_power/major_power to subject ranks, `overlord_must_be_higher_rank = no`. This changes the dominion type globally (judgment). Lower-impact alternative: set those five countries to `country_type = colonial` in country_definitions. The ranks part is a precaution because I could not evaluate runtime ranks.

Needs a new state region (or a different capital/states choice). The 2 capital errors and 2 country_creation errors stay in the log.
2. **Interest group assertion** (`Additional Interest Group Types database objects added; update CInterestGroupTypeDatabase::ExpectedNumItems`): CWP adds `ig_bureaucrats` (9 types, engine expects the vanilla 8). Debug assertion in the engine; cannot be silenced by data. Only removing ig_bureaucrats would stop it.
3. **Other assertions**: `GameStateAccess ... Interface/Hidden`, `War.GetWarParticipant(...)`, `Trying to reposition an invalid formation` are engine-side asserts at runtime without a script location; no data fix identified.

Which one depends on runtime ranks (CWP also has an extra `superpower` rank). Options: delete the pact, or REPLACE `countries_are_valid_rivals` with a looser trigger. Not written because I cannot evaluate which clause fails.
5. **state.cpp warnings (history/buildings vs state resources)**: 43 "building type X which it cannot support, it will be removed" (7313), 48 "has N of building type X and can only support M" (7329), 39 "using an excess of N arable land" (7337). They come from mod-owned `common/history/buildings/*.txt` vs `map_data/state_regions/*.txt` (`arable_resources`, `capped_resources`, `resource` blocks). Not patched: history/buildings cannot be REPLACE-patched per state (one top-level `BUILDINGS`), and a full rewrite would need design decisions.
