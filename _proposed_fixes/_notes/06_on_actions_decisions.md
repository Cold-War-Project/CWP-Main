# 06_on_actions_decisions - proposed fixes

Scope: common/on_actions, decisions, scripted_buttons, scripted_progress_bars, journal_entries, flag_definitions, dynamic_country_map_colors, dynamic_country_names, coat_of_arms. Logs read: error.log, error.1.log, error.2.log, error.3.log (586 distinct file:line error sites in scope; every one lies inside a patched block). No file outside `_proposed_fixes` was edited.

## How the patches were produced
- Vanilla top-level blocks were extracted by script, minimal line edits applied by a rule engine, and each changed block written to `zz_cwp_fix_<original name>.txt` as `REPLACE:<block> = {...}`. Braces were checked for balance on every output file. Every replacement target was verified to exist in the mod (technology, buildings, building groups, goods, laws, ideologies, government types, ai strategies, ship types, cultures, country definitions). Any `@variable` used by a patched block is re-declared at the top of its patch file (flag_definitions).
- Rules (00_mapping.md plus the deviations below): mapped key -> CWP key; dead trigger -> `always = no` in place (also inside OR / NOT so the logic stays valid); dead effect line or block -> deleted; trigger parameter blocks with a dead target (`culture_percent_state = { target = cu:x }`, `law_stance = { law = ... }`, `institution_investment_level`) -> the whole block becomes `always = no`; effect blocks with a dead target (`create_diplomatic_pact = { country = c:TEK }`, `create_country`, `create_pop`, `create_character`) -> block deleted.
- Journal entry blocks: none of the patched JE blocks is in 999_unwanted_journal_entries.txt (checked), so the `zz_` file does not resurrect a block the mod already neutralised.

## Deviations from 00_mapping.md (please review)
- Country tags: only BHT->HND, IDN/DEI->IDS, MAD->MGS, ZAN->ZZB, BCE->SRI are substituted, and only in simple tag tests (`exists = c:X`, `c:X ?= this/ROOT`, `region_state:X`, `change_tag = X`). Every other dead tag (PRU, HRE, RHN, HOH, UNL, BEI, TPG, SPC, PLT, RSM, HER/KUN/MAI/KAF, ORA/TRN/NAL, ALK, ATL, TIS, FND, RYU, TEK, TUA, SCM, LIP, PNI/CTR/PAU/EQT, AFS, CLI) becomes `always = no` or the effect is deleted, including `was_formed_from = X`. Reason: mapping them to GER/BRZ/SAF/AFH would make e.g. the `yellow_prussia` and `hre_*` map colours, the Hohenzollern candidature or the Boer-republic logic fire for CWP countries (a tag cannot be `was_formed_from` itself either).
- Cultures: mapped as in 00_mapping.md everywhere except three button files whose whole premise is a sub-culture that does not exist in CWP. In `06_vernacular_buttons.txt` (aragonese, asturleonese, galician, francoprovencal, occitan), `brazilian_scripted_buttons.txt` (nordestino, sulista, paulista, amazonic) and `05_struggle_for_the_highveld_buttons.txt` (griqua) the culture references are treated as dead so the buttons stay unavailable, instead of e.g. adding Khoisan as a primary culture or removing Brazilian homelands.
- Buttons that would otherwise have become pressable because a dead tag sat under NOT/NOR were forced unavailable (the NOT/NOR block is replaced by `always = no`): `je_confederation_of_the_rhine_confederate_button`, `je_buy_alaska_button` (visible), `je_unite_the_nations_proclaim_turtle_island_button`, `je_global_test_button` and `je_global_test_button_2`, and `ban_opium_button`.
- Ryukyu progress bars: the whole `c:RYU ?= { ... }` scoring body is replaced by `add = 0` (the rivalry cannot work without the RYU tag).
- `civilizing_mission` and `colonization` have no CWP equivalent -> `always = no`, so decisions/buttons gated on them (colonial expeditions, canal decisions, Raj, Tibet, ...) are unavailable until you pick CWP gates. Other 1836 techs follow the mapping (academia / international_relations_theory / ...).
- Frankenstein/promethean easter egg in `on_monthly_pulse_country`: both `if` blocks are removed entirely (promethean culture and the Ingolstadt company do not exist). The Florence Nightingale `create_character` (template GBR_florence_nightingale missing) is deleted.
- `japan_shinto` and `07_japan_religion_buttons`: buddhist_moralist and shinto_moralist both map to `ideology_moralist`, so the remove+add pair is effectively a no-op (kept to stay faithful; drop the decision if unwanted).
- `06_reconquista_buttons`: the `create_country` (SC1..SC4) effects are deleted, leaving an empty `hidden_effect`; the event that follows still fires.
- Manila cathedral logic in on_actions: has_building -> `always = no`, remove_building / create_building lines deleted (no CWP monuments).
