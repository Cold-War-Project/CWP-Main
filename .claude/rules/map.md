# Map: provinces, state regions, regions, terrain

`map_data` and `map_data/state_regions` are in `replace_paths`. The mod's map was synced to vanilla 1.15 on 2026-11-05 (782 land state regions, same ids, names, provinces and impassables as vanilla); resources, traits and ports are the mod's own. Vanilla's map is the priority when the two disagree on geometry.

## Files in `map_data`

| File | Kind | Notes |
|---|---|---|
| `provinces.png` | binary | Each province is one RGB colour; its id is `xRRGGBB` (upper-case hex). Do not edit by script. |
| `heightmap.*`, `indirection_heightmap.png`, `packed_heightmap.png`, `rivers.png`, `nodes.dat` | binary | Map editor output only. |
| `default.map` | text | Names the files above; `sea_starts = { }`, `lakes = { }` province lists; `wrap_x`. A water province missing from these lists is treated as land. |
| `adjacencies.csv` | text, `;` separated | `From;To;Type;Through;start_x;start_y;stop_x;stop_y;adjacency_rule_name;Comment`: sea crossings and straits. |
| `province_terrains.txt` | text, generated | `xRRGGBB="terrain_key"` per province. Marked "do not modify unless you know what you are doing"; regenerated by the map editor from painted materials. |
| `state_regions/NN_region.txt` | text | State region definitions, `99_seas.txt` for sea regions. **LF line endings**, BOM. |

## State regions

```
STATE_EXAMPLE = {
	id = 575                                   # unique; land ids below the sea range (seas start at 3000)
	subsistence_building = "building_subsistence_farms"
	provinces = { "x112233" "x445566" }
	impassable = { "x445566" }                 # optional
	prime_land = { "x112233" }                 # optional
	traits = { "state_trait_x" }
	city = "x112233"  farm = "x..."  mine = "x..."  wood = "x..."
	port = "x..."                              # coastal only; must be a coastal province of this region
	arable_land = 30
	arable_resources = { "bg_wheat_farms" "bg_livestock_ranches" }
	capped_resources = { bg_coal_mining = 40  bg_logging = 12 }
	resource = { type = "bg_oil_rig"  undiscovered_amount = 12  amount = 0  depleted_type = "..." }   # repeatable
	naval_exit_id = 3000                       # coastal only: id of the adjacent sea region
	min_cold_effect = 0.1  max_cold_effect = 0.8   # optional
	graphical_culture = "x"                    # optional override
}
```
Sea regions: `STATE_SEA_X = { id = 3000 provinces = { "x..." } }`, exactly one province.

Rules:
- Every province belongs to exactly one state region. Hub provinces (`city`, `farm`, `mine`, `wood`, `port`) must be in that region's `provinces` and not impassable.
- `arable_resources`, `capped_resources` keys and `resource.type` are **building group** keys from the mod's `common/building_groups` (resource groups must have `capped_by_resources` / `discoverable_resource` set). A vanilla group the mod removed (e.g. gold fields, rubber, whaling) must not appear.
- Resource numbers come from the design source `F:/Github/personal stuff/state resources origin.md` (vanilla-era borders; mapped onto mod states by province share, half-up rounding, logging folded into arable land). Compare against that file, not vanilla, when a resource looks wrong. The file lists Khorasan's oil as capped by mistake; it is an oil `resource` block.
- Changing a state region's provinces, id or name ripples into: `history/states`, `history/pops`, `history/buildings`, `common/strategic_regions`, `common/geographic_regions`, `country_formation`/`country_creation` state lists, `common/history/military_formations`, loc (`STATE_X`, `HUB_NAME_STATE_X_*`), map object data and city placement. Grep the state key across the whole mod before and after.
- `naval_exit_id` must be the sea region the port actually touches. `hq.cpp ... Failed to find a travel position for HQ` lines for countries without a usable port are on the ignore list (civil-war/secession tags); for a normal country they mean a wrong port/naval exit. STATE_PANAMA's city/port were restored to vanilla for exactly this reason.
- State keys are `STATE_UPPER_SNAKE`. Scripts use `s:STATE_X`.

## Strategic and geographic regions

- `common/strategic_regions`: `region_x = { capital_province = xRRGGBB  map_color = { r g b }  states = { STATE_A STATE_B }  graphical_culture = "x" }`. **Every state region must be in exactly one strategic region** (land and sea alike; `water_strategic_regions.txt` holds seas). Keys are used as `sr:region_x` and in military HQs (`hq_region`), interests, AI and loc.
- `common/geographic_regions`: `geographic_region_x = { short_key = "europe"  strategic_regions = { sr:region_a }  state_regions = { STATE_A } }`. Purely for script: creates `is_in_geographic_region` checks and the iterator families `any/every/random/ordered_country_in_<short_key>`, `..._state_in_<short_key>`, `..._state_region_in_<short_key>`. Vanilla scripted content uses many of these; removing a geographic region breaks every script that iterates it, so check with grep first. Optional loc `<key>_desc`.

## State traits

`state_trait_x = { icon = "..." modifier = { state_ / building_ modifiers } disabling_technologies = { tech } required_techs_for_colonization = { tech } }`. Vanilla trait files still load; the mod overrides through `zz_vanilla_state_traits.txt`. Traits whose modifiers name removed buildings/goods must be overridden; tech keys must be mod techs. Traits are attached in `state_regions` (`traits = { }`) or by script (`add_state_trait`).

## Terrain, straits, travel

- `common/terrain/01_terrain.txt`: terrain types (`combat_width`, `risk`, `weight`, `label`, textures/materials, `pollution_mask_strength`, `devastation_mask_strength`). Keys are what `province_terrains.txt` assigns. `common/labels` attaches battle modifiers to terrain labels.
- `common/strait_definitions`: `x = { type = natural/artificial  first_land_endpoint = xAAAAAA  second_land_endpoint = xBBBBBB  first_sea_endpoint = x...  second_sea_endpoint = x...  total_block_requires_full_control = no  military_block_requires_full_control = no  grievance_mult = 1.0 }`. Canal buildings point at one with `strait = key`.
- `common/travel_network/naval_network.txt`: generated node graph for sea travel. Do not hand-edit.
- `common/terrain_manipulators`: how building hubs repaint terrain; referenced by `terrain_manipulator =` on buildings.

## Harvest conditions

`common/harvest_condition_types`: weather events on states or seas. Keys per vanilla `.md`: `area_type = land/sea`, `trigger`, `time`, `incompatible_with`, `range = { integer_range = { min max } }`, `duration = { fixed_range = { } }` (weeks), `modifier`, `intensity`, `chance`, `color`, `icon`, `graphics = none/drought/flood/frost/wildfire`, `map_texture`, `naval_battle_condition` (sea only). The mod's file must only use mod building/goods modifiers.

## Map graphics tied to the map

City/hub placement, building meshes and map objects live under `gfx/map` (see `gui-gfx.md`). The mod overwrites `gfx/map/city_data/city_types/*` and `city_centerpiece/*` so they do not reference removed vanilla buildings.
